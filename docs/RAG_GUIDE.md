# RAG System Guide

The RAG (Retrieval-Augmented Generation) system enables:

1. Code chunking and embedding
2. Semantic search across codebases
3. Context-aware code explanations
4. Documentation generation
5. Code review automation

## Components

- Embeddings: Code embedder with chunk splitting
- Retrieval: Semantic search and similarity matching
- LLM: Multi-provider support (OpenAI, Anthropic, Groq)
- Chains: Specialized chains for different tasks
